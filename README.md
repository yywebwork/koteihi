# こていひ！

家庭の固定費と支払い方法をまとめて管理する静的Webアプリです。仕様は [SPEC.md](SPEC.md) を参照してください。

## 手元で起動する

1. GitHubの `Code` → `Download ZIP` で確認したいブランチのファイルを取得し、ZIPを展開します。すでにリポジトリを取得している場合は、そのフォルダを使えます。
2. Python 3をインストールし、ターミナルで展開したフォルダ（`index.html` がある場所）を開きます。
3. 次のコマンドを実行します。Windowsで `python3` が見つからない場合は、`py -m http.server 8000 --bind 127.0.0.1` を使います。

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

4. ブラウザで [http://127.0.0.1:8000](http://127.0.0.1:8000) を開きます。終了するときはターミナルで Ctrl+C を押します。

同じブラウザで同じURLを開くと、登録したデータを引き続き利用できます。データはブラウザの localStorage に保存され、アプリから外部へのデータ送信は行いません。バックアップは「設定」から保存できます。

## ファイル構成

- `index.html` と `style.css` は画面の骨組みと表示スタイルです。
- `app.mjs` は画面表示と操作を担当します。
- `data.mjs` は保存、形式検証、月額換算、カード状態の計算を担当します。

ビルド工程や外部ライブラリは不要です。
